# Retail Sales Analytics — SQL + Power BI

This portfolio project demonstrates an end-to-end analytics workflow using 1,800 synthetic retail order records spanning 2023–2025.

## Files
- `retail_sales.csv` — source dataset
- `schema_and_setup.sql` — SQL schema
- `analysis_queries.sql` — 10 SQL analyses
- `powerbi_dax_measures.txt` — core DAX measures
- `powerbi_build_guide.md` — model and dashboard instructions
- `sql_results.xlsx` — query result tabs for validation
- `executive_summary.md` — sample findings and recommendations
- `dashboard_preview.png` — static design reference
- `SQL_PowerBI_Project_Guide.pdf` — project brief

## Questions answered
1. What drives sales and profit across category and region?
2. How does discount level relate to profit margin?
3. Which subcategories and customers lead on sales?
4. What do monthly sales/profit trends show?
5. Are there data-quality issues?

## Build workflow
Import the CSV into SQLite, run the SQL file, load the CSV into Power BI Desktop, create a Calendar table and measures, build the three report pages, and validate totals against SQL. The package is a starter project; it does not contain a native `.pbix` file because that must be saved from Power BI Desktop.
